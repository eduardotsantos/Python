================================================================================
INSTALACAO AUTOMATICA (RECOMENDADO)
================================================================================

1. Copie orion_pd_v3_deploy.zip para o servidor (ex: C:\temp)

2. Extraia o arquivo:
   - Clique direito > Extrair Tudo...
   - Ou no PowerShell:  Expand-Archive orion_pd_v3_deploy.zip

3. Abra o PROMPT DE COMANDO COMO ADMINISTRADOR

4. Execute o instalador:

   cd C:\temp\orion_pd_v3_deploy
   install_v3_windows.bat

   Se a aplicacao NAO estiver em C:\apps\rd_project_managementv45,
   informe o caminho:

   install_v3_windows.bat "D:\meu\caminho\da\app"

O script faz automaticamente:
   - Backup completo (codigo + bancos .db) em C:\backups\
   - Para a aplicacao (servico Windows "OrionPD" ou App Pool do IIS;
     se rodar por python/waitress, pede para voce parar manualmente)
   - Copia todos os arquivos
   - Instala dependencias novas (usa venv se existir em BASE_DIR\venv)
   - Aplica migracao do banco (localiza o .db automaticamente)
   - Valida a instalacao
   - Reinicia a aplicacao


================================================================================
INSTALACAO MANUAL (PASSO A PASSO)
================================================================================

1. BACKUP (IMPORTANTE!)
------------------------
Prompt de Comando como Administrador:

    xcopy C:\apps\rd_project_managementv45 C:\backups\orion_backup_%date:~-4,4%%date:~-7,2%%date:~-10,2% /E /I


2. EXTRAIR O PACOTE
--------------------
    - Clique direito no .zip > Extrair Tudo
    - Ou PowerShell: Expand-Archive orion_pd_v3_deploy.zip


3. PARAR A APLICACAO
---------------------
Servico Windows:
    net stop OrionPD

IIS:
    %windir%\system32\inetsrv\appcmd stop apppool /apppool.name:"OrionPD"

Python/Waitress direto:
    Feche a janela do processo ou:
    taskkill /F /IM python.exe
    (CUIDADO: mata TODOS os processos Python)


4. INSTALAR DEPENDENCIAS NOVAS
-------------------------------
    pip install Flask-Babel==4.0.0 Flask-Mail==0.9.1 Babel==2.14.0

    Se usar virtualenv:
    C:\apps\rd_project_managementv45\venv\Scripts\pip install Flask-Babel==4.0.0 Flask-Mail==0.9.1 Babel==2.14.0


5. COPIAR ARQUIVOS
-------------------
Na pasta extraida do pacote:

    set APP=C:\apps\rd_project_managementv45

    xcopy app.py "%APP%\" /Y
    xcopy models.py "%APP%\" /Y
    xcopy extensions.py "%APP%\" /Y
    xcopy babel.cfg "%APP%\" /Y
    xcopy requirements.txt "%APP%\" /Y

    xcopy routes\*.py "%APP%\routes\" /Y
    xcopy services\*.py "%APP%\services\" /Y
    xcopy templates "%APP%\templates\" /E /I /Y
    xcopy translations "%APP%\translations\" /E /I /Y

    mkdir "%APP%\deploy" 2>nul
    xcopy migrate_password_reset.py "%APP%\deploy\" /Y

ARQUIVOS NOVOS NESTA VERSAO:
    services\email_service.py              <- envio via SMTP do tenant
    templates\auth\forgot_password.html    <- tela "esqueci minha senha"
    templates\auth\reset_password.html     <- tela de nova senha
    translations\ (completo)               <- .po e .mo dos 3 idiomas
    deploy\migrate_password_reset.py       <- migracao do banco


6. EXECUTAR MIGRATION
----------------------
    cd C:\apps\rd_project_managementv45

Saida esperada:

================================================================================
CONFIGURACAO DO SMTP DO TENANT (OBRIGATORIO P/ RESET DE SENHA)
================================================================================
O email de redefinicao usa o SMTP configurado na EMPRESA do usuario:

    1. Logar como superadmin
    2. Empresas > Editar empresa
    3. Secao "Configuracao de Email":
       - Habilitar envio de emails: SIM
       - Servidor SMTP: smtp.gmail.com (exemplo)
       - Porta: 587  |  Seguranca: TLS
       - Usuario SMTP: email@empresa.com
       - Senha SMTP: (para Gmail, usar Senha de App)
       - Remetente Padrao: Orion P&D <email@empresa.com>

Se o tenant NAO tiver SMTP configurado, o sistema usa as variaveis
de ambiente globais (defina no sistema ou no servico):

    setx MAIL_SERVER smtp.gmail.com /M
    setx MAIL_PORT 587 /M
    setx MAIL_USERNAME email@empresa.com /M
    setx MAIL_PASSWORD senha-de-app /M
    setx MAIL_USE_TLS True /M
    setx MAIL_DEFAULT_SENDER "Orion P&D <email@empresa.com>" /M

    (reinicie o servico apos definir as variaveis)
